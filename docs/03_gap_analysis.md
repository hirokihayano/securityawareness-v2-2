# セキュリティアウェアネス：Gap分析（現状とあるべき姿の課題抽出）

## 概要

本ドキュメントでは、「01_current_problems.md（現状の問題点）」と「02_ideal_state.md（本来あるべき姿）」を対比し、そのギャップを課題として抽出・整理する。各課題には重要度（高/中/低）と優先度を付与し、今後の施策検討の基礎資料とする。

---

## Gap分析サマリー

| 領域 | 現状（SANS成熟度推定） | あるべき姿 | Gap |
|------|----------------------|-----------|-----|
| 全体 | **Level 1〜2**（Non-Existent〜Compliance-Focused） | **Level 4〜5**（Long-Term Culture Change〜Optimization） | **2〜3レベルの乖離** |
| 人的側面 | リスク行動が常態化、知識と行動のギャップ | 全従業員が脅威を識別し即時報告できる | 大 |
| 組織的側面 | 年1回の形式的教育、経営層コミットメント不足 | 体系的・継続的教育、経営層スポンサーシップ | 大 |
| 技術的側面 | プラットフォーム未整備、AI対応遅延 | HRM基盤、行動分析、ゼロトラスト | 大 |
| 文化的側面 | 報告をためらう文化、IT部門任せ | 心理的安全性、全員参加、称賛文化 | 大 |

## 1. 人的側面のGap

### GAP-H1: リスクある行動の常態化 vs セキュアな行動習慣

| 項目 | 内容 |
|------|------|
| **重要度** | 🔴 高 |
| **優先度** | 1 |
| **現状** | 従業員の70%以上がリスクある行動を自認（パスワード使い回し、不審メールのクリック、未承認デバイス使用）。利便性を優先する傾向が根強い |
| **あるべき姿** | パスワードマネージャー・MFA利用が標準化、クリアデスク遵守、セキュアなリモートワーク習慣が定着 |
| **Gap** | セキュリティの知識はある程度あっても、日常業務での実践に全く結びついていない。行動変容を促す仕組みが欠如している |
| **影響** | データ侵害の88%が盗まれた認証情報を伴う（Verizon DBIR 2025）。直接的なインシデント発生リスク |

### GAP-H2: フィッシング・ソーシャルエンジニアリングへの脆弱性

| 項目 | 内容 |
|------|------|
| **重要度** | 🔴 高 |
| **優先度** | 2 |
| **現状** | AI生成フィッシング、QRコードフィッシング、TOAD、MFAバイパス攻撃など新手法への対応が追いつかない。実践的な訓練機会がない |
| **あるべき姿** | 全従業員がAI生成攻撃を含む最新脅威を識別可能。フィッシングシミュレーションクリック率≤5%、月次演習を実施 |
| **Gap** | 模擬フィッシング演習が未実施のため、実際の脅威対応力が測定・強化されていない。最新の攻撃手法に対する教育も不足 |
| **影響** | フィッシングとプリテキスティングがコスト最大のデータ侵害の主因 |

### GAP-H3: インシデント報告行動の欠如

| 項目 | 内容 |
|------|------|
| **重要度** | 🔴 高 |
| **優先度** | 3 |
| **現状** | インシデント報告をためらう文化（報告すると叱責される懸念）。報告率・報告時間ともに測定されていない |
| **あるべき姿** | 不審メール報告率≥70%、インシデント報告までの時間≤1時間、報告者を称賛する文化 |
| **Gap** | 報告を奨励する仕組み・文化がなく、初動対応の遅延がインシデントの拡大につながる |
| **影響** | 検知の遅延は侵害コストの直接的な増加要因（IBM: 早期検知で平均190万ドル削減） |

### GAP-H4: 内部不正・不注意による情報漏えい対策

| 項目 | 内容 |
|------|------|
| **重要度** | 🟡 中 |
| **優先度** | 6 |
| **現状** | 内部不正がIPA 10大脅威第4位（10年連続）、不注意による漏えいが第10位。退職者による持ち出し、メール誤送信、クラウド設定ミスが頻発 |
| **あるべき姿** | 人事部門による入退社時アクセス管理の徹底、情報分類レベルに基づく適切なデータ取扱い、DLPの運用 |
| **Gap** | 役割別のセキュリティ要件が定義・教育されておらず、特にデータ取扱いに関する実践的な教育が不足 |
| **影響** | 情報漏えいによるレピュテーション損害、法的責任 |

## 2. 組織的側面のGap

### GAP-O1: 形式的な教育 vs 体系的・継続的な教育プログラム

| 項目 | 内容 |
|------|------|
| **重要度** | 🔴 高 |
| **優先度** | 1 |
| **現状** | 年1回のeラーニング受講が主流。受講率のみをKPIとし、理解度・行動変容を測定しない。汎用的な内容で部門固有のリスクに未対応 |
| **あるべき姿** | 四半期マイクロラーニング、月次フィッシング演習、役割別専門研修、理解度テスト・行動評価による継続的改善 |
| **Gap** | 教育の頻度・形式・内容・効果測定のすべてにおいて大きな乖離。年1回→月次〜四半期への頻度向上、受講率→行動変容へのKPI転換が必要 |
| **影響** | 形式的な教育では行動変容が起きず、セキュリティ意識が根付かない。SANS成熟度Level 2に留まる主因 |

### GAP-O2: 経営層のコミットメント不足 vs 経営層スポンサーシップ

| 項目 | 内容 |
|------|------|
| **重要度** | 🔴 高 |
| **優先度** | 2 |
| **現状** | セキュリティをIT部門の問題として矮小化。経営層自身のリテラシーが低い。予算・人員の優先度が低い |
| **あるべき姿** | CISO/CROレベルの直接的支援、取締役会での定期議論、十分な予算とリソース確保、トップが率先してセキュリティ行動を実践 |
| **Gap** | 経営層の認識と関与が根本的に不足。経営課題としてのセキュリティ位置づけ変革が必要 |
| **影響** | 予算・人員・権限すべての施策の根幹。経営層コミットメントなしには他の課題解決が困難 |

### GAP-O3: セキュリティ人材の不足 vs 専任チーム体制

| 項目 | 内容 |
|------|------|
| **重要度** | 🔴 高 |
| **優先度** | 4 |
| **現状** | セキュリティ専門人材が慢性的に不足（日本国内で数万人規模）。教育企画・実施できる人材不在。CISO設置率が低い |
| **あるべき姿** | 最低2.8 FTEの専任担当者（SANS推奨）、長期的には4+ FTE、CISO設置、クロスファンクショナル連携 |
| **Gap** | 多くの組織で専任担当者がゼロまたは兼務。2.8 FTE確保は中小企業にとって極めて困難。外部リソース活用や段階的な体制構築が必要 |
| **影響** | 人材なしにはプログラムの企画・運営・改善サイクルが回らない |

### GAP-O4: ポリシーの形骸化 vs 実効性あるポリシー運用

| 項目 | 内容 |
|------|------|
| **重要度** | 🟡 中 |
| **優先度** | 5 |
| **現状** | ポリシーが存在するが浸透していない。実務と乖離し現場で無視される。インシデント対応手順が未周知 |
| **あるべき姿** | 平易な言葉でのポリシー記述、年1回以上のレビュー・更新、全従業員の承認ログ管理、例外管理プロセス |
| **Gap** | ポリシーの作成・更新プロセスに現場の声が反映されず、「机上の空論」化している |
| **影響** | ポリシーが機能しなければ、セキュリティ統制の基盤が崩壊する |

## 3. 技術的側面のGap

### GAP-T1: セキュリティ教育プラットフォームの未整備

| 項目 | 内容 |
|------|------|
| **重要度** | 🔴 高 |
| **優先度** | 3 |
| **現状** | フィッシングシミュレーション環境なし。リアルタイムのリスク可視化・ダッシュボードなし。適応型教育未提供 |
| **あるべき姿** | LMS、フィッシングシミュレーション、ゲーミフィケーション、マイクロラーニング、HRMプラットフォーム（行動分析・適応型トレーニング・AI駆動型リスク評価） |
| **Gap** | 教育・訓練・測定を支えるテクノロジー基盤が全面的に欠如。手動運用では体系的プログラムの実現が不可能 |
| **影響** | プラットフォームなしにはGAP-O1（体系的教育）の解決が困難。技術基盤は他の施策の前提条件 |

### GAP-T2: AI・シャドーITガバナンスの欠如

| 項目 | 内容 |
|------|------|
| **重要度** | 🔴 高 |
| **優先度** | 5 |
| **現状** | 97%の組織がAI関連インシデントを経験、63%がAIガバナンスポリシー未整備。シャドーAIが蔓延 |
| **あるべき姿** | AIの業務利用に関する明確なポリシー・ガイドライン、適切なアクセス制御、定期的な利用状況監査 |
| **Gap** | 生成AIの急速な普及に対してガバナンスが全く追いついていない。ポリシー策定と教育の両面で対応が急務 |
| **影響** | 機密情報のAIサービスへの入力、不正確なAI出力の業務利用など、新種のリスクが制御不能 |

### GAP-T3: インシデント検知・対応の自動化不足

| 項目 | 内容 |
|------|------|
| **重要度** | 🟡 中 |
| **優先度** | 7 |
| **現状** | SIEM/SOAR等の自動化ツールの導入が遅延。アラート疲れにより重要インシデントを見逃すリスク |
| **あるべき姿** | SIEM/SOARとHRMプラットフォームの統合、ヒューマンファクターの可視化、AI駆動型の継続的リスク評価 |
| **Gap** | 人的要因に起因するインシデントの検知・対応が手動中心で、迅速な対応ができない |
| **影響** | AI活用組織は平均190万ドルのコスト削減を実現（IBM）。未導入は相対的な競争劣位 |

### GAP-T4: リモートワーク・ゼロトラスト対応の遅延

| 項目 | 内容 |
|------|------|
| **重要度** | 🟡 中 |
| **優先度** | 8 |
| **現状** | VPN脆弱性、クラウド設定不備、私用デバイス管理不足。ゼロトラストの導入が進んでいない。IPA 10大脅威第6位 |
| **あるべき姿** | ゼロトラストアーキテクチャ、特権アクセス管理（PAM）、パスワードレス認証（FIDO2/WebAuthn）、EDR/XDR全端末展開 |
| **Gap** | 境界型防御からゼロトラストへのアーキテクチャ転換が未完了。技術的投資と従業員教育の両面が必要 |
| **影響** | リモートワーク環境が攻撃の侵入経路となるリスクが継続 |

## 4. 文化的側面のGap

### GAP-C1: 罰則ベースの報告忌避文化 vs 心理的安全性に基づく報告文化

| 項目 | 内容 |
|------|------|
| **重要度** | 🔴 高 |
| **優先度** | 2 |
| **現状** | ミスや不審事象の報告をためらう文化。報告すると叱責される懸念がインシデントの隠蔽・遅延を招く |
| **あるべき姿** | 報告しても非難されない心理的安全性。報告者を称賛する「See Something, Say Something」文化。学習・改善ベースのアプローチ |
| **Gap** | 組織の根本的な姿勢・文化の転換が必要。罰則から学習へ、非難から称賛へのパラダイムシフト |
| **影響** | 報告文化なしにはインシデントの早期検知・対応が不可能。全施策の効果を左右する基盤的課題 |

### GAP-C2: 「IT部門任せ」 vs 「全員の責任」

| 項目 | 内容 |
|------|------|
| **重要度** | 🔴 高 |
| **優先度** | 4 |
| **現状** | セキュリティはIT部門の問題という認識。一般従業員の当事者意識が低い |
| **あるべき姿** | 「セキュリティは全員の責任」の共通認識。一人ひとりが「ヒューマンファイアウォール」としての自覚を持つ |
| **Gap** | セキュリティの「自分事化」ができていない。セキュリティチャンピオン制度等による各部門でのリーダーシップが欠如 |
| **影響** | 組織の防御力の根幹。当事者意識なしには技術的対策も十分に機能しない |

### GAP-C3: セキュリティ文化醸成施策の不在

| 項目 | 内容 |
|------|------|
| **重要度** | 🟡 中 |
| **優先度** | 6 |
| **現状** | セキュリティ月間イベント、チャンピオンプログラム、表彰制度、経営層メッセージ等の文化醸成施策が実施されていない |
| **あるべき姿** | 定期的なイベント、セキュリティチャンピオン育成、表彰制度、行動科学（ナッジ理論等）の活用 |
| **Gap** | 文化は意図的に醸成しなければ自然には生まれない。計画的・継続的な文化醸成プログラムが必要 |
| **影響** | 文化なくしてはあらゆる施策が一時的な効果に留まり、持続的な行動変容に至らない |

## 5. 外部環境対応のGap

### GAP-E1: 急速に進化する攻撃手法への対応遅延

| 項目 | 内容 |
|------|------|
| **重要度** | 🔴 高 |
| **優先度** | 3 |
| **現状** | 生成AI悪用フィッシング、ディープフェイク、RaaS、MFAバイパス等の新手法が急増。攻撃は日々進化するが教育は年1回 |
| **あるべき姿** | 最新脅威情報の迅速な全社共有、臨時研修の即時実施、適応型教育によるリアルタイム対応 |
| **Gap** | 脅威の進化スピードと教育の更新スピードに大きな乖離。脅威インテリジェンスの活用と教育の連動が必要 |
| **影響** | AI生成フィッシングは手作業の4.5倍成功率が高い（Microsoft）。対応遅延は直接的な被害拡大 |

### GAP-E2: サプライチェーンセキュリティ教育の欠如

| 項目 | 内容 |
|------|------|
| **重要度** | 🟡 中 |
| **優先度** | 7 |
| **現状** | サプライチェーン攻撃がIPA 10大脅威第2位（7年連続）。委託先・取引先経由の侵入増加。自社対策のみでは不十分 |
| **あるべき姿** | 調達部門のサプライチェーンリスク評価能力、委託先へのセキュリティ要件適用、パートナーを含む教育の拡張 |
| **Gap** | 自社従業員向けの教育すら不十分な状態で、サプライチェーン全体の教育は手つかず |
| **影響** | 中小企業が踏み台として狙われ、大企業含むサプライチェーン全体が被害を受ける |

### GAP-E3: 規制・法令対応の複雑化への未対応

| 項目 | 内容 |
|------|------|
| **重要度** | 🟡 中 |
| **優先度** | 8 |
| **現状** | 改正個人情報保護法、GDPR、NIS2指令、経済安全保障推進法、業種別ガイドラインへの対応負荷が増大 |
| **あるべき姿** | ISO 27001/NIST CSF準拠の体系的プログラム、監査エビデンスの自動収集、コンプライアンス状況のリアルタイム把握 |
| **Gap** | 各規制の要件を満たすための教育・記録管理が断片的で、統合的なコンプライアンス管理ができていない |
| **影響** | 法令違反による罰金・制裁、取引機会の喪失 |

## 7. Gap間の依存関係

一部の課題は他の課題の前提条件となっており、取り組み順序を考慮する必要がある。

```
GAP-O2 経営層コミットメント
  │
  ├──► GAP-O3 人材確保（予算承認が前提）
  │      │
  │      └──► GAP-O1 体系的教育プログラム（運営人材が前提）
  │             │
  │             ├──► GAP-H1 行動変容（教育プログラムが前提）
  │             ├──► GAP-H2 フィッシング対応力（演習が前提）
  │             └──► GAP-E1 最新脅威対応（教育更新体制が前提）
  │
  ├──► GAP-T1 プラットフォーム導入（予算承認が前提）
  │      │
  │      ├──► GAP-H2 フィッシング演習（ツールが前提）
  │      ├──► GAP-T2 AIガバナンス（管理基盤が前提）
  │      └──► GAP-T3 自動化（技術基盤が前提）
  │
  └──► GAP-C1 報告文化（経営層メッセージが起点）
         │
         ├──► GAP-H3 報告行動強化
         └──► GAP-C2 「全員の責任」意識
               │
               └──► GAP-C3 文化醸成プログラム
```

**最重要の起点**: GAP-O2（経営層コミットメント）が解決されなければ、予算・人材・権限の確保ができず、他の多くの課題に着手できない。
