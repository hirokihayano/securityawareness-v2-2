# SecureHub - セキュリティ文化変革プラットフォーム

従来の知識偏重型セキュリティ研修から脱却し、**「知っている」から「行動する」**への変革を実現するプラットフォームです。匿名インシデント報告、AI脅威情報配信、エグゼクティブダッシュボードを通じて、組織全体のセキュリティ文化を醸成します。

## 主な機能

| 機能 | 説明 |
|------|------|
| **ダッシュボード** | KPI、リスクスコア推移、脅威フィード、直近インシデント一覧 |
| **インシデント報告** | ワンクリック匿名報告。心理的安全性を確保した報告フロー |
| **脅威情報フィード** | 深刻度別フィルタリング、AIによる要約、タグ分類 |
| **匿名Q&A** | 匿名質問投稿、公式回答、投票機能 |
| **エグゼクティブダッシュボード** | 経営層向けKPI、部門別分析、ROI指標 |
| **プレゼンテーションモード** | スライドナレーション、音声Q&A、ライブデモ統合 |

## 技術スタック

- **フレームワーク:** Next.js 16 (App Router)
- **言語:** TypeScript
- **UI:** React 19 + Tailwind CSS 4
- **チャート:** Recharts
- **AI:** Claude API (Anthropic SDK)

## セットアップ

### 前提条件

- Node.js 18+
- Claude API キー（Q&A機能用）

### インストール

```bash
# 依存パッケージのインストール
npm install

# 環境変数の設定
cp .env.example .env
# .env ファイルに Claude API キーを設定
# CLAUDE_API="your-api-key"
```

### 起動

```bash
# 開発サーバー
npm run dev
# http://localhost:3000 でアクセス

# 本番ビルド
npm run build
npm start
```

## 開発ロードマップ

| フェーズ | 期間 | 内容 |
|----------|------|------|
| Phase 1 | 0〜2ヶ月 | MVP: ワンクリック報告 + 基本ダッシュボード |
| Phase 2 | 2〜4ヶ月 | ニュースフィード、Q&A、Slack/Teams連携 |
| Phase 3 | 4〜5.5ヶ月 | チャンピオン管理、エグゼクティブダッシュボード |
| Phase 4 | 5.5〜7ヶ月 | AIチャットボット、自動トリアージ、要約機能 |

## 目標指標

- インシデント報告数: 0件 → 50件以上/月
- 報告までの時間: 数日 → 1時間以内
- SANS成熟度: Level 2 → Level 4
- フィッシングクリック率: ≤ 5%
- 報告率: 0% → ≥ 70%
